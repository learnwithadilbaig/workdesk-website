FAQ

Questions people ask first

What is WorkDesk?

WorkDesk is HR and payroll software for growing businesses in Pakistan. It keeps employee records, attendance, leave, payroll, tasks, performance scorecards and reports in one system with one login.

Can I start with just attendance or just payroll?

Yes. Most teams start with one or two modules and add the rest later. Your employee data carries over, so nothing has to be set up twice.

Does payroll handle fines, advances and loans?

You define the rules once: late arrivals, absences, advances, loan instalments or any other deduction. WorkDesk applies them from attendance each payroll run and shows every line on the payslip. Read more on the payroll page.

How long does it take to move from spreadsheets?

Send us your current employee and salary sheets. We import them, set up your policies with you, and check the first payroll run alongside you. Our guide on moving HR off Excel walks through the steps.
